## Portfolio Website

This repository also contains a responsive, single-file portfolio website.

### Publish with GitHub Pages

1. Create a public GitHub repository named `nxtgeninventors-dev.github.io` (the name must match the GitHub account username).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for deployment to finish. The site should appear at `https://nxtgeninventors-dev.github.io/`.

If the GitHub username differs from `nxtgeninventors-dev`, use `<actual-username>.github.io` as the repository name and update the GitHub profile links in `index.html`.

### Personalisation

The website currently uses a text monogram instead of a portrait and includes the details supplied for the portfolio. Edit `index.html` to add verified project names, photographs, school details or further contact links.
